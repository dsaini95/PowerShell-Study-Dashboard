# PowerShell-Study-Dashboard

A lightweight PowerShell GUI application designed to centralize important Microsoft PowerShell documentation and learning resources in one place.

## Features

- Quick access to official Microsoft PowerShell documentation
- PowerShell Language Reference
- Cmdlet Reference
- About Topics (about_*)
- PowerShell Gallery
- Desired State Configuration (DSC)
- PowerShell Remoting
- Active Directory Module Documentation
- Group Policy Documentation
- Dark-themed user interface

## Why I Built This

While learning and working with PowerShell, I found myself constantly switching between multiple browser tabs, bookmarks, and notes.

This dashboard was created to reduce context switching and provide a single location for frequently used PowerShell resources.
